# Football Data Portraits
Trends and phenomena in football data.

## Data Sources
### Pro Football Reference
This project scrapes player and team data from [Pro Football Reference](https://www.sports-reference.com/data_use.html) in compliance with their [data](https://www.sports-reference.com/data_use.html) and [bot traffic](https://www.sports-reference.com/bot-traffic.html) site terms.

## Installation
```
pip install -r requirements.txt
```
